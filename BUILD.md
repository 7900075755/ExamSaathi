# ExamSaathi — Build Guide

## Project layout

| Path | What it is |
|---|---|
| `www/` | The web app (HTML/CSS/JS, question data, fonts, icons). **Edit the app here.** |
| `android/` | Native Android project generated by Capacitor. Commit it; don't edit `android/app/src/main/assets/public/` (overwritten on every sync). |
| `capacitor.config.json` | App id (`com.examsaathi.app`), name, splash/status-bar settings. |
| `package.json` | Pinned Capacitor 8.6.0 + plugins (app, splash-screen, status-bar). |

## Requirements (to build the APK)

- Node.js **22+**
- **JDK 21** (Android Studio's bundled JDK is fine)
- Android SDK Platform **36** + Build-Tools (installed via Android Studio's SDK Manager)
- Android Studio **2025.1 (Narwhal) or newer** recommended (Android Gradle Plugin 8.13, Gradle 8.14.3)

The app runs on Android **7.0+** (minSdk 24), targets Android 16 (targetSdk 36).

## Everyday workflow

```bash
npm install                 # first time only
npm run serve               # test in a browser: http://localhost:8080
npm run sync                # copy www/ into the Android project after any change
npm run open:android        # open in Android Studio
```

## Debug APK (for testing on your phone)

```bash
npm run build:debug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

Copy the APK to the phone and install it (allow "install unknown apps").

## Release build (Google Play)

1. Create an upload key **once** and keep it safe (losing it means you can't
   update the app without Play support):
   ```bash
   keytool -genkey -v -keystore examsaathi-upload.jks -keyalg RSA -keysize 2048 \
           -validity 10000 -alias examsaathi
   ```
   Never commit `*.jks` / passwords (already in `.gitignore`).
2. In Android Studio: **Build → Generate Signed App Bundle / APK → Android App Bundle**,
   choose the key → produces `app-release.aab` for Play Console.
3. Before every new upload, increase `versionCode` (and `versionName`) in
   `android/app/build.gradle`.

> The app id `com.examsaathi.app` becomes permanent once published on Play.

## Regenerating icons / splash

Source artwork: `www/assets/icons/icon.svg`. The PNGs in `www/assets/icons/` and
`android/app/src/main/res/mipmap-*` / `drawable*/splash.png` were rendered from it.
After changing the SVG, re-render them (e.g. with `@capacitor/assets`, or by
exporting the same sizes from any vector editor).

## Notes

- The service worker (offline cache) is used only in the browser/PWA. In the
  Android app it is disabled, because files are already bundled and a cache
  would keep serving old code after an update.
- When changing any file in `www/` for the browser/PWA version, bump
  `CACHE_STATIC` / `CACHE_DATA` in `www/service-worker.js`.
